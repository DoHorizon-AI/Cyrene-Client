# IDE 式工作台

本轮将 Client 改为紧凑的深色工具窗口布局，参考 JetBrains IDE 的侧边工具栏、编辑器标签和可收起面板。实现使用现有 React 与 LiteGraph，不增加界面框架，也不修改其他仓库或 IDE 项目结构。

## 区域与操作

| 区域 | 功能 |
| --- | --- |
| 顶部菜单 | 文件：草稿、恢复、导入导出、服务端列表；编辑：排版与撤销；视图：窗口、构建输出与运行详情；构建：检查、执行计划、镜像构建与版本启用；运行：预检、启停、恢复、变更和制品；工具：节点包、服务器与 MCP |
| 顶部工具栏 | 流程名称、服务端保存、自动排版、本地预演、Web Host 连接 |
| 左侧 | 项目文件、节点库、服务器管理；同一侧每次显示一个窗口 |
| 中央 | 流水线画布、当前草稿 JSON 和本地文本文件的只读标签页 |
| 右侧 | 节点信息与服务设置、内置页面入口、平台 MCP 工具与任务上下文 |
| 底部 | 构建输出、真实运行管理、流程检查、本地预演、当前会话提示；窄窗口标签可水平滚动 |

点击当前工具图标或面板关闭按钮收起窗口。拖动侧栏边界与底栏顶部调整尺寸；分隔条也支持方向键调整，Shift 加方向键以更大步长调整。菜单支持上下方向键、Escape 和点击外部关闭。

Ctrl/Cmd+S 保存浏览器草稿；Ctrl/Cmd+Z 撤销本地修改，Ctrl/Cmd+Shift+Z 或 Ctrl/Cmd+Y 重做。撤销/重做快捷键保留输入框内原生文字编辑行为。Alt+1/2/3 切换项目文件、节点库、服务器管理，Alt+0 切换节点信息，Alt+9 收起/展开底部窗口。Delete 仅在画布获得焦点且未预演时删除选中节点；侧栏输入、菜单和只读文件预览不会触发画布快捷键。

窗口尺寸、显示状态保存在 `cyrene.studio.layout.v1`，与流程文档分开。视图菜单可恢复默认布局。窄窗口采用覆盖式侧栏，并避免左右面板同时展开；刷新窄窗口默认收起两侧。布局偏好不提交到服务端或 MCP。

## 当前边界

- 本地文件通过用户显式选择读取，只在浏览器会话中保留。最多列出 1000 个文件，文本预览/流程导入限单文件 1 MB。文件夹以相对路径列表显示；没有完整文件树、写回、删除、Git 操作或跨刷新目录授权。
- JSON 标签为当前草稿的只读视图；修改继续通过节点表单、画布或现有 MCP 工具完成。导入后切回画布。
- 服务器管理复用登记应用服务，可核对受信 observer 返回的在线 Node 身份。尚未装配真实远端 Agent、远端终端或 GPU 观测提供方。
- 页面插件栏先提供 JSON 与流程检查两个内置页面入口；第三方插件发现、加载、权限、训练曲线等页面尚未实现。
- MCP 面板从本地控制服务读取实际工具名称和读写属性。任务草稿只保存在当前页面内存中，复制内容包含流程 ID、当前节点 ID 和任务文字。用户应先保存到服务端，再在已配置 Client MCP 的外部 AI 客户端使用。没有内置模型请求、聊天历史或“发送即执行”。
- “事件日志”是当前会话提示。构建面板另读持久化构建事件，并链接 GitHub 完整输出；运行面板读提供方事件、代次及制品引用。构建/运行菜单与面板复用 hook 的状态、禁用条件和幂等键；关闭面板不取消服务端任务。见 [构建控制](node-builds.md)。
- 运行菜单增加“核对运行状态与事件”；底栏使用 SSE 游标续读，离线保留最近状态并显示重连提示。恢复草稿包含服务端双版本基线，刷新后仍可合并独立修改并拒绝重叠覆盖。见 [控制服务](distributed-control.md)。

## 验证

浏览器测试覆盖菜单键盘操作、窗口切换保留参数、拖动/键盘缩放、刷新后布局恢复、文件预览、画布快捷键隔离、真实 MCP 工具目录及剪贴板上下文、390/760 像素窄窗口无水平溢出。同时保留原有画布、设置接口、服务器登记和并发同步回归用例。
