# Echo Web UI / Echo Web 界面

The `src/` module provides an Echo evaluation workbench inside the shared Client Product surface. It creates exact-match suites, imports reference/actual JSONL through Echo's API, binds inputs to a published Catalyst data-tools package, and shows/downloads Echo's persisted report. It is not a separate npm package or downloadable UI bundle.

`src/` 模块在 Client 共享 Product 页面中提供 Echo 评测工作台。它可创建精确匹配套件、通过 Echo API 导入 reference/actual JSONL、将输入绑定到 Catalyst 已发布的数据工具包，并展示/下载 Echo 持久化报告。当前仍没有独立 npm package 或可下载 UI bundle。

See [`src/README.md`](src/README.md) for the module files and evaluation path.
