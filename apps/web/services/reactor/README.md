# Reactor Web UI / Reactor Web 界面

Reserved for an independently buildable Reactor UI module. Model and deployment settings remain integrated in the shared workbench; no standalone package or downloadable bundle exists yet.

此目录预留给可独立构建的 Reactor UI 模块。模型与部署设置界面仍集成在共享工作台中；当前没有独立 package 或可下载 bundle。
